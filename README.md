# Dashboard ติดตามงานเปลี่ยนทดแทน — GitHub Pages

Dashboard ภาษาไทย อ่านไฟล์ Excel ที่ Export จาก SAP และสรุปงาน/งบประมาณรายสัปดาห์ ใช้ GitHub Pages ได้โดยไม่ต้องมี Render, Python server หรือฐานข้อมูลกลาง หน้าตาและตัวกรองเหมือนรุ่นเดิม

- รองรับ Excel `.xlsx`, Excel รุ่นเก่า `.xls`, SAP HTML/XML export และ CSV UTF-8/Windows-874
- แยกงบ 2xxx / 3xxx, HB (2567–2568), JA (2568–2569), M4 (2569), กฟฟ. และสถานะ
- เก็บประวัติด้วย IndexedDB ในเบราว์เซอร์ ไม่ส่งไฟล์ที่นำเข้าไป GitHub
- เปรียบเทียบแต่ละสัปดาห์ด้วย WBS ส่งออก CSV และสำรอง/กู้คืนประวัติ JSON
- ไม่มีระบบล็อกอินตามที่ผู้ใช้เลือก

## ใช้งาน

เปิดเว็บไซต์ กด “นำเข้าข้อมูลประจำสัปดาห์” เลือกวันที่ข้อมูลจริงและไฟล์ SAP ดิบ แล้วเลือกวันที่เพื่อเทียบครั้งก่อน วันที่ซ้ำจะถูกปฏิเสธเพื่อรักษาประวัติเดิม

หลังนำเข้าให้กด “สำรองประวัติทั้งหมด” เก็บ JSON ลงเครื่อง ใช้ “กู้คืนประวัติ” เมื่อต้องเปลี่ยนเครื่อง หรือย้ายจากระบบ Render เดิม โดยใช้ JSON ที่สำรองจากระบบเดิมได้

ประวัติอยู่ในเบราว์เซอร์และโดเมนที่ใช้งาน คนละเครื่อง/คนละเบราว์เซอร์จะมีประวัติแยกกัน ล้างข้อมูลเว็บไซต์หรือใช้โหมดส่วนตัวอาจทำให้ประวัติหาย การ deploy หน้าเว็บใหม่ไม่ลบ IndexedDB ของผู้ใช้เมื่อโดเมนเดิมยังอยู่ สำรอง JSON ไว้เสมอ

## เปิดเว็บในเครื่องเพื่อพัฒนา

```sh
python3 build_pages.py
python3 -m http.server 8000 --directory _site
```

`build_pages.py` คัดลอกหน้าเว็บ ไลบรารีอ่าน Excel และ JSON ตั้งต้นไป `_site` ไม่คัดลอก SQLite หรือ credentials ใช้ relative paths จึงรองรับ URL ของ GitHub Pages ที่มีชื่อ repository เป็น subdirectory

## วิธีคำนวณ

- งบปัจจุบัน = `งบประมาณปัจจุบัน` ของ SAP
- เบิกจริง = `รวม Act.ทั้งหมดที่ควบคุม งปม.` ไม่บวกคอลัมน์ Act ย่อยซ้ำ
- คงเหลือ = `งบประมาณคงเหลือ` ที่ SAP รายงาน อาจต่างจากงบปัจจุบันลบเบิกจริง
- จำนวนเงินเก็บเป็นสตางค์ ใช้เฉพาะงาน Lv 5 กลุ่ม HB/JA/M4 งบ 2xxx/3xxx ไม่รวมแถวสรุป Lv 3/4
- F4 หรือ SAP CLSD = ปิดงานแล้ว รหัสอื่นแสดงตามจริง ยังไม่กำหนดลำดับความคืบหน้า
- WBS ซ้ำที่ข้อมูลเหมือนกันนับครั้งเดียว ถ้าขัดแย้งปฏิเสธไฟล์ทั้งหมด
- เปรียบเทียบเฉพาะงบที่มีในทั้งสองไฟล์ งานไม่พบในไฟล์ใหม่ไม่ถือว่าปิดแล้ว
- ค่าเริ่มต้นตามชีตตัวอย่าง เลือก “งานย่อย SAP ทั้งหมด” เพื่อดูงานนอกตัวอย่าง กฟฟ. ของงานนอกตัวอย่างยังไม่ระบุ
- ค้นหา/สถานะ/เฉพาะงานเปลี่ยนใช้กับตารางและ CSV ตัวกรองด้านบนใช้กับยอดรวมและกราฟ

ข้อมูลตั้งต้นวันที่ 5 ต.ค. 2569: ตามตัวอย่าง 334 งาน งบ 109,518,090.58 บาท เบิกจริง 78,828,008.90 บาท (`data/seed.json`, `data/reference.json`) ข้อมูลตั้งต้นนี้รวมในหน้าเว็บ ส่วน SAP ที่นำเข้าใหม่อยู่เฉพาะเบราว์เซอร์ผู้ใช้

## ทดสอบ

```sh
node --test test_parser.cjs
node --check static/app.js
```

ทดสอบ parser, วันจริง, การตัดแถวซ้ำ, เงินสตางค์, ไฟล์สำรอง และยอดตั้งต้น โดย workflow GitHub Pages รัน parser tests ก่อน deploy

## รุ่นมีเซิร์ฟเวอร์ (ทางเลือกเดิม)

`app.py`, Dockerfile และ `render.yaml` เก็บไว้เป็นทางเลือก ไม่จำเป็นสำหรับ GitHub Pages หากต้องใช้ประวัติร่วมกันผ่านเซิร์ฟเวอร์ ให้ติดตั้ง `requirements.txt`, รัน `setup.py` และ `app.py` แล้วเปิดหน้าเว็บพร้อม `?storage=server` โหมดนี้ใช้ API/SQLite กลางแทน IndexedDB ดู [DEPLOY.md](DEPLOY.md)
